# RV32I Pipeline CPU

北京理工大学计算机组成与设计课程项目记录：基于 Verilog/Vivado 的 RV32I 五级流水线 CPU 与 FPGA 外设系统。

## 结构

- `rtl/`：CPU、控制、立即数生成、寄存器堆、统一存储器、数码管、VGA 和辅助外设模块。
- `asm/`：中断、数码管和综合测试程序。
- `sim/`：课程阶段使用的模块仿真 testbench。
- `constraints/`：开发板引脚及时钟约束示例。

## 项目特性

- 支持 31 条 RV32I 指令，采用五级流水线。
- 团队完成数据前推、Load-Use 停顿、静态分支处理和外部中断联调。
- 本人主要负责内存映射外设、汇编测试程序与板级验证；实现按钮消抖、三模式八位数码管和 640×480@60 Hz 无帧缓冲 VGA 显示。

这是从课程工程中提取的可读源码记录，不包含 Vivado 缓存、综合产物、比特流或个人实验材料。
